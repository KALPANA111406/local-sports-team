# Local Sports Team Website

## About the Project
The Local Sports Team Website is a simple and responsive website that helps users explore local sports teams, join teams, and schedule matches.

## Features
- View local sports teams.
- Search teams by name.
- Filter teams by sport.
- Join or leave a team.
- Schedule upcoming matches.
- Cancel scheduled matches.
- Save data using browser Local Storage.
- Responsive design for desktop and mobile devices.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Project Structure
```text
local-sports-team/
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run the Project
1. Download or clone this repository.
2. Open the project folder.
3. Double-click `index.html` to open the website in your browser.

## Data Storage
This project uses browser Local Storage to save team and match information. The saved data is available in the same browser on the same device.
